# CSUniMap

**CSUniMap** is a campus mapping project focused on creating an interactive digital map of the **Caraga State University (CSU) Main Campus**.

The project is currently in its early development stage, with the initial work focused on establishing the project's core structure, map data, and web interface.

## Project Goals

The primary goal of CSUniMap is to provide a simple and accessible way for students and visitors to explore the CSU Main Campus and locate important areas and facilities.

## Planned Development

The project is planned to develop progressively through the following stages:

* [ ] Establish the core application and server
* [ ] Develop the initial campus map
* [ ] Integrate campus roads and pathways
* [ ] Add campus buildings and locations
* [ ] Implement interactive map navigation
* [ ] Add information for selected buildings and locations
* [ ] Implement building rating functionality
* [ ] Add designated meeting or hangout locations
* [ ] Improve the overall user interface and experience
* [ ] Conduct testing and refinement

Additional features may be considered as development progresses and as project requirements allow.

## Technology

The project currently uses:

* **C++** — Core application and server
* **HTML** — Web structure
* **CSS** — Interface styling
* **JavaScript** — Client-side interaction
* **CMake** — Build system

## Project Status

> **Early Development**

CSUniMap is currently being developed as a student group project. The project's structure and planned features may change throughout development as the team evaluates requirements, technical feasibility, and available development time.

## Future Direction

Future development will focus on improving the accuracy and usability of the campus map while gradually introducing additional functionality that can help users navigate and interact with campus locations.
